## 서버 API (`server/worker.js`)
- `GET /v1/all` → `{v:1, t, p:{사람id: {at, pr, lg, rev, t}}}`
- `PUT /v1/p/<사람id>` 본문 `{at, pr, lg}` → 더 나중(at)에 바꾼 기록이 서버에 있으면 409와 그 기록을 돌려줘요. 단, 서버 기록이 비어 있으면(고른 답·주문 0개) 막지 않아요(11/27 고침: 테스트로 담았다 뺀 빈 기록 때문에 폰의 진짜 기록이 빈 걸로 덮이던 문제). 저장할 때마다 이전 판을 90일 동안 `h:<id>:<rev>`에 남겨요(`GET /v1/h/<id>`, `?rev=N`).
- 사람 id는 상경·경민·경호·다혜·아름·순영 6명만 받아요. 검사 규칙은 앱의 받은 코드 검사와 같아요.
